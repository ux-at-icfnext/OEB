# Welcome to the OEB Prototype

This is a design-validation prototype. It expresses the [Ontario Design System](https://designsystem.ontario.ca/) as working, in-browser code so teams can review real interactions and states before engineering migrates them into production. Design proven in code first, production build second — that separation is the point.
